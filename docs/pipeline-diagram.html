Acorn-to-A5000 Radar Pipeline

Simulated radar IQ samples leave the FPGA, cross PCIe straight into GPU memory, and come out as detections a fraction of a millisecond later. Figures are as measured on the test rig at the link's limit. Dashed outlines and pink tags show the planned integration with the AMS GRA RF MEL standard.

Holds each of the engine's read bursts until the generator has written that data, and counts what it has read.

overflow counter = samples lost

AMS VITA 49.2 packetizer

Frame the stream as Base Set signal data packets: stream ID, picosecond timestamp of the first sample, and a trailer whose sample-loss bit reports ring overflows. 32 KiB packets carry 8,184 IQ samples each for 0.1% overhead.

JobDataFormat::AMSVitaExtraLarge · payload format 0x200003CF (complex int16)
A link watchdog re-resets the PCIe core if the link isn't up ~260 ms after reset, so a cold boot still trains at x4.
PCIe Gen2 x4 · GPUDirect RDMA 5 GT/s × 4 lanes · 1.50 GB/s sustained

Planned: AMS GRA integration

The Agile Mission Suite Government Reference Architecture splits a mission system into sensors, which expose hardware through the RF MEL C++ API (librf_mel.so), and skills, which consume that data and publish UCI reports. Its starter kit adds an environment simulator (Supercell) flying an ownship and two bandit aircraft over Kitty Hawk, NC, and a 3D viewer (Worldview). Our rig can fill both the sensor and the skill roles, with the FPGA echoing the simulated aircraft.

Open question: waveform. At 375 MS/s a range bin is 0.4 m, so 4,096 bins reach only about 1.6 km. Aircraft at tactical ranges need a lower rate (25 MS/s gives 6 m bins out to about 24 km), but at an X-band carrier that pulse rate only covers about ±46 m/s unambiguously, too slow for jets. That calls for a deliberate waveform choice or Doppler ambiguity resolution.
